# Ideas

## Problema

Cuando una mascota se pierde, la información queda dispersa en grupos de WhatsApp, redes e historias que duran horas. No hay filtros, no hay mapa claro y coordinar con quien la vio suele depender de exponer el teléfono.

## Propuesta

Michinder concentra avisos de mascotas perdidas y encontradas con:

- Fotos, especie, sexo, edad, tamaño y descripción.
- Ubicación exacta y radio de búsqueda.
- Filtros y búsqueda por cercanía.
- Swipe para decidir rápido y grilla para revisar.
- Chat interno con límites anti-spam.
- WhatsApp opcional, solo con autorización del autor.
- Reportes y bloqueos para moderación básica.

## Público

Personas de Santa Fe que perdieron una mascota, la encontraron o quieren ayudar. El tono es cercano, directo y sin burocracia.

## Flujos principales

1. **Perdí**: inicio → “Perdí una mascota” → especie → fotos → ubicación/radio → publicar.
2. **Encontré**: inicio → “Encontré una mascota” → especie → fotos → ubicación/radio → publicar.
3. **Buscar**: explorar → filtros → swipe o grilla → detalle → chat o WhatsApp.
4. **Reencuentro**: el autor marca el aviso como reencontrado o lo elimina.
5. **Moderación**: cualquier usuario con cuenta reporta un aviso o bloquea a otra persona.

## Fuera de v1

- Notificaciones push o email.
- Panel de administración.
- Edición de fotos de avisos existentes.
- Chat en tiempo real con WebSockets.
- Verificación de identidad o de mascotas.
- Adopciones, donaciones o tienda.
